# Father Time — Feature Roadmap

## Shipped (v1.0 - v1.7)
- Time injection hook (every prompt)
- Peak hours (all timezones)
- Session timer
- Session health (context, compaction, turns, cache)
- Pace check (live API rate limits)
- Rate limit forecasting
- Subscription burn rate
- Daily briefing
- Activity patterns
- Focus mode
- Context budget (file token estimation with model comparison)
- Session cost estimate
- Compaction warning hook (60/75/85%)
- Update checker hook
- Usage data caching
- Current vs All Sessions view
- Interactive time-menu

## Next Up
- Project timer — cumulative time across all sessions per project
- Session history — log of past sessions (duration, tokens used, cost)
- Cost forecast — "at current pace, this project will cost ~$X this week"
- Compaction predictor — "at current growth rate, compaction in ~X turns"

## Future Ideas
- Multi-project dashboard — compare time/cost across projects
- Session export — generate a summary of what happened this session
- Budget alerts — "you've spent $X on Opus this week"
- Team mode — share usage stats across a team
- Weekly digest — automated weekly report of usage patterns
